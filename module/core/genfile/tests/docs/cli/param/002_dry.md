### EC-05: dry one shows preview no write

- **Given:** An archive is loaded in session state
- **When:** `.archive.save path::"out.json" dry::1` is run
- **Then:** Exit code 0; stdout shows `[DRY RUN]` preview lines; no file created on disk
- **Tests:** `tests/archive_commands_test.rs`

### EC-06: dry zero executes normally

- **Given:** An archive is loaded in session state
- **When:** `.archive.save path::"out.json" dry::0` is run
- **Then:** Exit code 0; file is written to disk; no `[DRY RUN]` prefix in output
- **Tests:** `tests/archive_commands_test.rs`

### EC-07: dry default is zero

- **Given:** An archive is loaded in session state
- **When:** `.archive.save path::"out.json"` is run (no `dry::` specified)
- **Then:** Exit code 0; file is written to disk (same behavior as `dry::0`)
- **Tests:** `tests/archive_commands_test.rs`

### EC-64: invalid dry value rejected

- **Given:** A valid command with `dry::2` (not a boolean 0/1)
- **When:** `.archive.save path::"out.json" dry::2` is run
- **Then:** Exit code 1; error message indicates invalid value for `dry::`
- **Tests:** `tests/archive_commands_test.rs`

### EC-65: dry one still returns error for invalid command

- **Given:** A command with invalid parameters and `dry::1`
- **When:** `.archive.load path::"nonexistent.json" dry::1` is run
- **Then:** Exit code 1; error reported even in dry-run mode (dry mode does not suppress errors)
- **Tests:** `tests/archive_commands_test.rs`

### EC-66: env variable sets dry

- **Given:** `GENFILE_DRY=1` is set in the environment; no `dry::` parameter given
- **When:** `.archive.save path::"out.json"` is run
- **Then:** Exit code 0; stdout shows `[DRY RUN]` preview; no file written to disk
- **Tests:** `tests/archive_commands_test.rs`
