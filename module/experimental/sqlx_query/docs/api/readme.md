# API Doc Definition

### Scope

- **Purpose**: Describe the public interface a consumer's build script calls.
- **Responsibility**: Index the API doc instances: operations, settings, errors, compatibility.
- **In Scope**: Operations, settings, produced directives, error handling, and compatibility guarantees.
- **Out of Scope**: Decision rationale (→ `feature/`) and correctness properties (→ `invariant/`).
